## 二、短信发送流程图

```
【客户端】
    │
    │ POST /sms/single_send
    │ {apikey, mobile, text, sign}
    ▼
┌─────────────────────────────────────────────────────────┐
│ 【beacon-api 接口模块】                                  │
│                                                         │
│  1. 参数校验：                                           │
│     ├─ API Key校验（Redis查询客户信息）                 │
│     ├─ IP白名单校验                                      │
│     ├─ 签名校验                                          │
│     ├─ 模板校验                                          │
│     └─ 费用校验                                          │
│                                                         │
│  2. 生成唯一ID：                                         │
│     └─ 雪花算法生成 sequenceId                          │
│                                                         │
│  3. 发送到MQ：                                          │
│     └─ RabbitMQ: sms_pre_send_topic                    │
└─────────────────────────────────────────────────────────┘
    │
    │ MQ消息
    ▼
┌─────────────────────────────────────────────────────────┐
│ 【beacon-strategy 策略模块】                             │
│                                                         │
│  1. 策略校验链（顺序执行）：                             │
│     ├─ blackGlobal：全局黑名单（Redis查询）             │
│     ├─ blackClient：客户黑名单                          │
│     ├─ dfaDirtyWord：敏感词过滤（DFA算法）             │
│     ├─ limitOneMinute：每分钟限流（Redis ZSet）        │
│     ├─ limitOneHour：每小时限流                        │
│     ├─ fee：费用校验                                    │
│     └─ route：路由选择                                  │
│                                                         │
│  2. 路由选择算法：                                       │
│     ├─ 从Redis获取客户绑定的通道                        │
│     ├─ 按权重降序排序                                   │
│     ├─ 检查通道可用性                                   │
│     ├─ 匹配运营商（全网通/移动/联通/电信）             │
│     └─ 选择第一个满足条件的通道                         │
│                                                         │
│  3. 发送到网关队列：                                     │
│     └─ RabbitMQ: sms_gateway_topic_{channelId}        │
└─────────────────────────────────────────────────────────┘
    │
    │ MQ消息（按通道分发）
    ▼
┌─────────────────────────────────────────────────────────┐
│ 【beacon-smsgateway 网关模块】                           │
│                                                         │
│  1. 监听通道队列：                                       │
│     └─ 每个通道有专属队列                               │
│                                                         │
│  2. 封装CMPP协议：                                      │
│     └─ 构建CMPP_SUBMIT包                               │
│                                                         │
│  3. Netty发送：                                         │
│     └─ TCP长连接发送到运营商网关                        │
│                                                         │
│  4. 存储映射关系：                                      │
│     └─ sequenceId → StandardSubmit（内存Map）          │
└─────────────────────────────────────────────────────────┘
    │
    │ TCP长连接（CMPP协议）
    ▼
┌─────────────────────────────────────────────────────────┐
│               【运营商网关】                              │
└─────────────────────────────────────────────────────────┘
    │
    │ CMPP_SUBMIT_RESP（第一次响应）
    ▼
┌─────────────────────────────────────────────────────────┐
│ 【beacon-smsgateway 网关模块】                           │
│                                                         │
│  1. 接收提交应答：                                       │
│     └─ 获取msgId（运营商生成的短信ID）                  │
│                                                         │
│  2. 存储映射关系：                                      │
│     └─ msgId → StandardSubmit（内存Map）               │
│                                                         │
│  3. 发送到搜索模块：                                     │
│     └─ RabbitMQ: sms_write_log_topic（写入日志）      │
└─────────────────────────────────────────────────────────┘
    │
    │ CMPP_DELIVER（第二次响应：状态报告）
    ▼
┌─────────────────────────────────────────────────────────┐
│ 【beacon-smsgateway 网关模块】                           │
│                                                         │
│  1. 接收状态报告：                                       │
│     ├─ 解析状态：DELIVRD=成功，其他=失败                │
│     └─ 根据msgId找到原始消息                            │
│                                                         │
│  2. 判断是否需要回调：                                   │
│     └─ 查询Redis：isCallback、callbackUrl              │
│                                                         │
│  3. 发送到推送模块：                                     │
│     └─ RabbitMQ: sms_push_report_topic（如果需要）    │
│                                                         │
│  4. 发送到死信队列：                                     │
│     └─ 延迟10秒更新ES日志                              │
└─────────────────────────────────────────────────────────┘
    │
    │ 分成两个分支
    ├──────────────────────────┬──────────────────────────┐
    ▼                          ▼                          ▼
┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│ 【beacon-push】  │  │【beacon-search】  │  │【beacon-search】  │
│   推送模块       │  │   搜索模块       │  │   搜索模块       │
│                 │  │                 │  │                 │
│ 1. HTTP回调：    │  │ 1. 写入ES：      │  │ 1. 更新ES：      │
│    POST客户地址  │  │   首次写入日志   │  │   更新状态报告   │
│                 │  │                 │  │                 │
│ 2. 判断响应：    │  │ 2. 索引：        │  │ 2. 延迟队列：    │
│    成功=结束     │  │   sms_submit_   │  │   延迟10秒更新   │
│    失败=重试     │  │   log_{year}    │  │                 │
│                 │  │                 │  │                 │
│ 3. 重试机制：    │  │ 3. 文档ID：      │  │                 │
│    最多5次       │  │   sequenceId    │  │                 │
│    0/15/30/60/  │  │                 │  │                 │
│    300秒延迟     │  │                 │  │                 │
└──────────────────┘  └──────────────────┘  └──────────────────┘
    │
    │ HTTP POST
    ▼
┌──────────────────┐
│   客户回调地址   │
│  (客户系统)      │
└──────────────────┘
```

## 三、CMPP协议交互时序图

```
【网关模块】                    【运营商网关】
     │                              │
     │  ──CMPP_CONNECT───────────▶  │
     │                              │
     │  ◀──CMPP_CONNECT_RESP──────  │
     │                              │
     │  连接建立成功，保持长连接      │
     │                              │
     │  ──CMPP_SUBMIT────────────▶  │
     │  (sequenceId: 12345)         │
     │                              │
     │  ◀──CMPP_SUBMIT_RESP───────  │
     │  (msgId: 67890)              │
     │  第一次响应：提交应答          │
     │  存储映射：sequenceId→msgId   │
     │                              │
     │                              │  [运营商处理短信]
     │                              │
     │  ◀──CMPP_DELIVER───────────  │
     │  (msgId: 67890, stat: DELIVRD)│
     │  第二次响应：状态报告          │
     │  根据msgId找到原始消息         │
     │  更新状态：成功/失败           │
     │                              │
     │  ──CMPP_DELIVER_RESP───────▶ │
     │  确认收到状态报告              │
     │                              │
     │  [定时心跳保活]                │
     │  ──CMPP_ACTIVE_TEST────────▶ │
     │  ◀──CMPP_ACTIVE_TEST_RESP──  │
     │                              │
```

```
           ▼
```

## 六、限流算法流程图

```
请求到达
  │
  ▼
┌─────────────────────┐
│ 构建Redis Key        │
│ limit:minute:       │
│ {clientId}:{mobile} │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 获取当前时间戳       │
│ now = currentTime   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Redis ZAdd           │
│ score = now          │
│ value = now          │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Redis ZRemRangeBy   │
│ Score               │
│ 删除1分钟前的数据    │
│ (0, now - 60000)    │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Redis ZCard          │
│ 统计当前ZSet中数量   │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 数量 > 限制？        │
│ (例如：5条/分钟)     │
└──────────┬──────────┘
           │
      ┌────┴────┐
      │ Yes     │ No
      │         │
      ▼         ▼
┌─────────┐  ┌─────────┐
│ 限流异常 │  │ 继续处理 │
```
